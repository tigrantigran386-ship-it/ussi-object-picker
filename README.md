# USSI Object Picker

Обёртка над [UniversalSynSaveInstance](https://github.com/luau/UniversalSynSaveInstance): показывает **дерево объектов игры** и сохраняет только то, что отмечено галочками — в один файл.

## Запуск в экзекьюторе

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/tigrantigran386-ship-it/ussi-object-picker/main/ussi_object_picker.lua"))()
```

## Как пользоваться

1. Раскрываешь сервис кнопкой `+` (как в Explorer).
2. Ставишь галочки на нужных объектах — можно из разных сервисов сразу.
3. Жмёшь «ЭКСПОРТИРОВАТЬ». Файл появится в `workspace/USSI_Export/` у экзекьютора.

Снятие галочки внутри отмеченной папки = исключение: папка сохранится, а этот ребёнок будет вырезан.

## Два режима

| Формат | Что получится | Как открыть |
|---|---|---|
| `.rbxl` как карта | объекты лежат на своих путях (`Workspace/Folder/House`), остальное отрезано | Studio → File → Open from File |
| `.rbxm` как модель | только выбранные объекты списком сверху | Studio → File → Insert from File |

## Чего скрипт не может

`ServerStorage`, `ServerScriptService` и серверные `Script`/`ModuleScript` клиенту не репликуются (FilteringEnabled) — в дереве они будут пустыми. Это не баг.

## Важно

* Инжект-скрипты нарушают ToS Roblox и детектятся Hyperion — используй твинк.
* Скрипт качает USSI с ветки `main` его репозитория (и сам USSI тянет зависимости из `SomeHub`). Это сторонний код, который автор может обновить в любой момент.
* Ассеты принадлежат их авторам: использование чужого в своём проекте — нарушение авторских прав.
